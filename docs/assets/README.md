# Illustrations / Abbildungen

## English

These assets are captures of the actual Cutterhoochee desktop application running generated qualification media: color/test-pattern footage, numbered frames, demonstration speech, music, and captions. They are not interface mockups or personal recordings. Illustrations accompany both user guides; the interface labels remain English.

| Asset | What it shows |
| --- | --- |
| `workspace-dark.png` | Full dark workspace: media library, Program preview, timeline, and assistant panel. |
| `workspace-light.png` | Full light workspace with the same editor layout. |
| `portrait-captions.png` | A portrait-format project with text/captions in its preview. |
| `export-success.png` | A completed portrait H.264/AAC export with SRT sidecar selected. |
| `clip-inspector.png` | The Inspector tab with a selected video clip. |
| `transcript-panel.png` | The initial Transcript panel and its source selector, local transcription, and SRT import controls; not a completed transcript. |
| `provider-settings.png` | Provider settings with the Anthropic API-key form selected and a blank key input. Connection/model counts are illustrative, not a guarantee of availability. |
| `playback.gif` | Actual Play/Pause workflow and changing preview frames, cropped to the preview and transport. |
| `timeline-seek.gif` | Actual scrubbing with the **Preview playhead** slider, cropped to the preview and transport. This is not a clip-drag or timeline-trimming demonstration. |
| `theme-switch.gif` | Actual full-workspace theme toggling, scaled down for documentation. |

Some earlier full-workspace screenshots contain an assistant conversation demonstrating a harmless `/usr/bin/printf` permission check. That conversation is a qualification example, not a recommended first editing task. Generic fixture filenames and an export job identifier may be visible. No API keys, tokens, account emails, or personal media are shown.

GIFs were encoded from successive real application screenshots, use optimized palettes, and loop silently. Their reduced frame rate and cropped/scaled presentation are for readability and file size. They do not measure playback speed, input latency, or audio synchronization. Use the adjacent numbered instructions as the accessible text alternative; the animations contain no unique instructions.

## Deutsch

Diese Dateien zeigen die tatsächlich laufende Cutterhoochee-Desktopanwendung mit generierten Testmedien: Farb- und Testmuster-Videos, nummerierte Einzelbilder, Beispielsprache, Musik und Untertitel. Es handelt sich weder um Oberflächenentwürfe noch um persönliche Aufnahmen. Die Abbildungen werden in beiden Handbüchern verwendet; die Oberflächenbeschriftungen bleiben Englisch.

| Datei | Inhalt |
| --- | --- |
| `workspace-dark.png` | Vollständige dunkle Arbeitsoberfläche mit Medienbibliothek, Vorschau, Timeline und Assistent. |
| `workspace-light.png` | Vollständige helle Arbeitsoberfläche mit derselben Anordnung. |
| `portrait-captions.png` | Hochformatprojekt mit Text/Untertiteln in der Vorschau. |
| `export-success.png` | Abgeschlossener H.264/AAC-Export im Hochformat mit ausgewählter SRT-Begleitdatei. |
| `clip-inspector.png` | Registerkarte **Inspector** mit ausgewähltem Videoclip. |
| `transcript-panel.png` | Anfängliche Registerkarte **Transcript** mit Quellenauswahl, lokaler Transkription und SRT-Import; kein fertiges Transkript. |
| `provider-settings.png` | Anbieter-Einstellungen mit ausgewähltem Anthropic-API-Schlüssel-Formular und leerem Schlüsselfeld. Verbindungsstatus und Modellanzahl sind Beispiele, keine Verfügbarkeitszusage. |
| `playback.gif` | Tatsächliche Wiedergabe mit wechselnden Vorschaubildern, auf Vorschau und Transportsteuerung zugeschnitten. |
| `timeline-seek.gif` | Tatsächliches Navigieren mit dem Regler **Preview playhead**, auf Vorschau und Transportsteuerung zugeschnitten. Keine Demonstration des Verschiebens oder Trimmens von Clips. |
| `theme-switch.gif` | Tatsächlicher Wechsel des Darstellungsthemas in der gesamten Arbeitsoberfläche, für die Dokumentation verkleinert. |

Einige ältere Gesamtansichten enthalten einen Assistenten-Dialog zu einer harmlosen Berechtigungsprüfung mit `/usr/bin/printf`. Dieser Dialog ist ein Prüfbeispiel und keine Empfehlung für den ersten Schnittauftrag. Generische Testdateinamen und die Kennung eines Exportauftrags können sichtbar sein. API-Schlüssel, Tokens, Konto-E-Mail-Adressen und persönliche Medien werden nicht gezeigt.

Die GIFs wurden aus aufeinanderfolgenden echten Screenshots erstellt, nutzen optimierte Farbpaletten und wiederholen sich ohne Ton. Die reduzierte Bildrate und die zugeschnittene beziehungsweise verkleinerte Darstellung dienen Lesbarkeit und Dateigröße. Die GIFs messen weder Wiedergabeleistung noch Eingabelatenz oder Audio-Synchronität. Die danebenstehenden nummerierten Anleitungen sind die zugängliche Textalternative; die Animationen enthalten keine zusätzlichen, nur dort erklärten Schritte.
